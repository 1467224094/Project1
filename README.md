# 简单版图书管理系统（C++ 课程设计）

一个结构简单的控制台版图书管理系统，适合作为大二《面向对象程序设计》课程设计：
4 个源文件、3 个头文件，约 800 行代码，只用 `vector`、`fstream`、继承和多态。

## 功能

- **登录**：管理员账号登录，连续 3 次错误则退出。
- **图书管理**：添加、修改、删除、显示全部、按书名/作者关键字查询。
- **读者管理**：添加学生/教师、修改、删除、显示全部。
- **借阅管理**：借书、还书、查看某读者的借阅情况。
- **统计信息**：图书种类与数量、读者人数、当前借出数量。
- **修改密码**：修改管理员密码。
- **数据保存**：所有修改都会写入 `library_data.txt`，下次启动自动读取，数据不会丢失。

## 默认账号

- 账号：`admin`
- 密码：`123456`

## 文件说明

| 文件 | 作用 |
| ---- | ---- |
| `Book.h` / `Book.cpp` | 图书类：编号、书名、作者、出版社、总量、可借数量 |
| `Person.h` / `Person.cpp` | 借阅人类（抽象基类）及学生、教师两个派生类 |
| `Library.h` / `Library.cpp` | 系统主类：登录、菜单、图书/读者/借阅/统计、数据读写 |
| `main.cpp` | 程序入口 |

## 继承与多态

```
Person（抽象基类：编号、姓名、院系、最大借阅量、已借图书）
 ├── Student（学生，最多借 3 本）
 └── Teacher（教师，最多借 10 本）
```

`Person` 中的 `getType()` 和 `show()` 是虚函数，`Library` 用 `vector<Person*>` 保存读者，
显示和借阅上限判断都通过基类指针完成。

## 数据文件

程序在运行目录生成 `library_data.txt`，每行一条记录，用 `|` 分隔：

```
ADMIN|admin|123456
BOOK|B001|C++ Primer|Lippman|人民邮电出版社|5|5
READER|1|S001|张三|计算机学院|3|B001
```

- `ADMIN`：管理员账号和密码
- `BOOK`：图书编号、书名、作者、出版社、总量、可借数量
- `READER`：类型（1 学生 / 2 教师）、编号、姓名、院系、最大借阅量、已借图书编号（逗号分隔）

把 `library_data.txt` 删除后重新运行，会恢复成自带的演示数据。

## 编译运行

用 Visual Studio 打开 `SimpleLibrary.slnx`（或直接打开 `SimpleLibrary.vcxproj`）后按 F5 运行。
工程已为所有配置添加 `/utf-8`，控制台输出中文不会乱码。
