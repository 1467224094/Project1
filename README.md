# 图书管理系统（C++ 课程设计）

一个控制台版的图书管理系统，用 C++ 实现，重点练习**继承、派生和多态**。
借阅人分为本科生、研究生、教师三种，图书资源分为图书、期刊、电子资源三种，
不同类型的人能借的资源种类和借期都不一样。

## 一、功能

程序启动后要先登录，分**管理员**和**借阅人**两种角色：

- 管理员可以用全部功能，默认账号 `admin`，密码 `123456`
- 借阅人用自己的学号或工号登录，默认密码 `123456`，登录后只能查看自己的
  信息、借书还书、看自己的借阅记录和查询图书
- 两种角色都可以修改自己的密码

具体功能：

1. 添加借阅人信息（本科生 / 研究生 / 教师）
2. 修改借阅人信息（姓名、院系、最大借阅数量、专业或职称）
3. 借书：检查库存、最大借阅数量、借阅权限、是否重复借阅
4. 还书：自动计算是否超期、超期多少天
5. 添加图书或资源信息（图书 / 期刊 / 电子资源）
6. 修改图书或资源信息
7. 查看图书信息，支持按编号、书名、作者、出版社模糊查询
8. 查看全部借阅记录、某个人的借阅记录、超期未还记录
9. 统计信息（人数、资源册数、在借数量、超期数量）
10. 数据保存到 txt 文件，下次运行自动读回来

## 二、文件说明

| 文件 | 作用 |
| --- | --- |
| `Person.h` / `Person.cpp` | 借阅人：基类 `Person`、学生 `Student`、`Undergraduate`、`Graduate`、`Teacher` 五个类都在这一对文件里 |
| `Book.h` / `Book.cpp` | 图书：基类 `Book`、`PaperBook`、`Journal`、`EBook` 四个类都在这一对文件里 |
| `BorrowRecord.h` | 借阅记录结构体（只有数据，没有操作，所以不用 cpp） |
| `Library.h` / `Library.cpp` | 管理类，负责增删改查、借书还书、登录检查、保存和读取 |
| `Menu.h` / `Menu.cpp` | 界面模块：登录、两种角色的菜单、各种输入检查 |
| `main.cpp` | 程序入口，只有 20 行左右 |
| `admin.txt` | 管理员账号和密码 |
| `persons.txt` | 借阅人数据 |
| `books.txt` | 图书资源数据 |
| `records.txt` | 借阅记录 |
| `build.bat` | 一键编译脚本 |
| `LibrarySystem.sln` | Visual Studio 2026 解决方案，双击就能打开 |
| `LibrarySystem.vcxproj` | VS 工程文件（C++17、UTF-8、x64/Win32 都配好了） |
| `test1.txt` ~ `test4.txt` | 测试用的输入脚本（重新运行前要先删掉数据文件） |
| `从零开始教程.md` | 手把手开发手册，按步骤从空文件夹做到这个系统 |

同一继承体系的类放在基类的那一对文件里：`Person.h` 里是借阅人的 5 个类，
`Book.h` 里是图书的 4 个类。头文件只写类的声明，函数实现都放在同名的 `.cpp` 里，
所以文件不多，但继承关系和虚函数一点没少。

界面代码单独放在 `Menu.cpp` 里，`main.cpp` 只做三件事：读数据、调用 `runSystem()`、
退出时保存，所以主函数很短，不会被几百行菜单淹没。

## 三、类的继承关系

```
                Person（抽象类）
                 /          \
            Student        Teacher
            /      \
   Undergraduate  Graduate

                 Book（抽象类）
                /     |      \
        PaperBook   Journal   EBook
```

`Person` 是抽象类，`getType()`、`getTypeName()`、`getLevel()`、`getBorrowDays()`、
`getExtra()` 都是纯虚函数，由下面的派生类实现。`Book` 也一样，
`getType()`、`getTypeName()` 是纯虚函数，另外提供了带默认实现的
`getNeedLevel()`、`getLoanDays()`、`getExtra()`，派生类按需要改写。

主要的成员：

- `Person`：编号、姓名、院系、最大借阅数量、已借数量
- `Student`：多一个专业属性
- `Teacher`：多一个职称属性
- `Book`：图书号、书名、作者、出版社、总数量、可借数量
- `Journal`：多一个期号，而且只有研究生和教师能借
- `EBook`：多一个访问地址

## 四、多态是怎么用的

1. `Library` 里用 `vector<Person*>` 和 `vector<Book*>` 保存基类指针，
   实际指向的是 `Undergraduate`、`Graduate`、`Teacher`、`PaperBook`、`Journal`、`EBook` 对象。
   调用 `p->show()`、`p->getBorrowDays()`、`b->getLoanDays()` 的时候会自动调用到派生类的版本。

2. 借书时的权限判断两边都用到虚函数：

```cpp
bool Person::canBorrow(Book* b) const
{
    return getLevel() >= b->getNeedLevel();
}
```

   权限等级约定：

   | 借阅人 | 等级 | 能借的资源 |
   | --- | --- | --- |
   | 本科生 | 1 | 图书、电子资源 |
   | 研究生 | 2 | 图书、期刊、电子资源 |
   | 教师 | 3 | 全部 |

   | 资源 | 需要的等级 | 借期 |
   | --- | --- | --- |
   | 图书 | 1 | 30 天 |
   | 期刊 | 2 | 15 天 |
   | 电子资源 | 1 | 7 天 |

   所以本科生借期刊会被拒绝，研究生和教师可以借，这就是"不同类型的借阅人
   借不同类型的资源"。

3. 借期取两边的较小值：`min(借阅人可借天数, 图书可借天数)`，
   比如教师最多 60 天，但图书只能借 30 天，那实际就是 30 天。

4. 以后如果要加新的类型（比如"校友"或者"光盘"），只要再写一个派生类，
   实现几个虚函数就行，借书、还书、显示的代码都不用改。

## 五、编译和运行

### 用 Visual Studio 2026 打开

双击 `LibrarySystem.sln`，VS 会直接打开工程，按 `F5` 就能编译并运行调试。
工程里已经配好了这些，不用再改属性：

- 语言标准 C++17，加了 `/utf-8`，源码里的中文不会乱码
- 源文件、头文件、数据文件都分好组放在解决方案资源管理器里
- 输出文件叫 `library.exe`，生成在 `x64\Release\` 或 `x64\Debug\` 下
- 调试时的工作目录是项目目录，所以能直接读写 `persons.txt` 这些数据文件

改完代码按 `Ctrl+F5` 重新生成并运行就行。

### 用 g++ 编译

方法一：双击 `build.bat`。

方法二：在命令行里执行

```
g++ -std=c++11 -O2 *.cpp -o library.exe
library.exe
```

编译需要 g++，C++11 及以上都可以。程序用 `SetConsoleOutputCP(65001)`
设置控制台编码，保证中文正常显示。

`build.bat` 里加了一句 `set LANG=C`，是因为 g++ 的汇编器在含中文的路径下
找临时文件会出问题，加上这句就能正常编译。如果不用 bat，手动编译时也要先设置一下。

程序里自带了一点示例数据：3 个借阅人（S001 本科生、S002 研究生、T001 教师）、
3 种资源（B001 图书、J001 期刊、E001 电子资源），还有 4 条借阅记录，
运行起来就能直接看到效果。

## 六、登录和使用说明

启动程序后先选身份登录：

```
========== 图书管理系统 ==========
  1. 管理员登录
  2. 借阅人登录
  0. 保存并退出
```

- 管理员：账号 `admin`，密码 `123456`
- 借阅人：输入学号或工号，密码默认 `123456`
- 密码输错可以再试 2 次，连续错 3 次就回到登录界面

管理员登录以后的菜单：

```
========== 管理员菜单 ==========
  1. 借阅人管理
  2. 图书资源管理
  3. 借阅与归还
  4. 查询与统计
  5. 修改密码
  0. 注销（回到登录界面）
```

借阅人登录以后的菜单：

```
========== 借阅人菜单 ==========
  1. 查看我的信息
  2. 借书
  3. 还书
  4. 查看我的借阅记录
  5. 查询图书
  6. 修改密码
  0. 注销（回到登录界面）
```

借阅人借书、还书的时候只要输入图书编号，借阅人编号自动用他自己登录的，
所以没办法借别人的书，也看不到别人的记录。

输入约定：

- 修改信息时，某项直接回车表示保留原来的值
- 需要输入文字的地方不能为空
- 删除之前会要求输入 `y` 确认
- 菜单里选 `0` 是注销，注销的时候会自动保存数据；在登录界面再选 `0` 才退出程序

数据文件在程序所在目录，是用制表符分隔的纯文本，可以直接用记事本打开看。
想从空数据开始，把 `admin.txt`、`persons.txt`、`books.txt`、`records.txt` 删掉即可，
管理员账号会自动变回 `admin` / `123456`。
